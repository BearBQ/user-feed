Программа USER-FEED

От себя добавил уникальное поле email у пользователей

Пользователи могут писать посты.
При запросе постов пользователя данные берутся из Redis (если есть).
Если в Redis нет — читаем из базы, кладём в Redis.

Создание пользователя и постов
POST /user — создать пользователя (name, email)
POST /post — создать пост (user_id, content)

Получение ленты (с кешем)
GET /feed/:user_id — получить все посты пользователя
